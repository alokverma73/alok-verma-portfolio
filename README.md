# Alok Verma — Portfolio

Personal portfolio website built with Flask, HTML, CSS and JavaScript.

## About

A modern portfolio showcasing my work across:

- Artificial Intelligence
- Cloud Computing
- Software Engineering
- Data & Analytics

## Tech Stack

- Python
- Flask
- Jinja2
- HTML5
- CSS3
- JavaScript
- JSON

## Features

- Responsive design
- Animated page transitions
- Project showcase
- Experience section
- Contact form
- Resume viewer
- Custom 404 page
- Mobile navigation
- Modular Jinja components
- JSON-based project and experience data
